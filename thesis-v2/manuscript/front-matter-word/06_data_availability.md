**Data Availability and Replication Materials**
:::

::: {custom-style="No Indent"}
All research materials necessary to replicate the analyses in this dissertation are publicly available at the following repository:
:::

**<https://github.com/fabioc-aloha/AIRS_Data_Analysis>**

The repository contains:

- **Anonymized Data:** Complete survey responses (*N* = 523) in CSV and JSON formats
- **Analysis Code:** Python and R scripts for all statistical analyses (EFA, CFA, SEM, cluster analysis)
- **Survey Instrument:** The full 28-item AIRS questionnaire as administered
- **Thesis Source:** Markdown source files and build scripts for this document
- **Figures and Tables:** All visualizations and statistical output

The data and code are released under dual licensing: MIT License for code and CC BY 4.0 for data and documentation. Researchers are encouraged to use these materials for replication, extension, or meta-analytic purposes with appropriate citation.

For questions about the data or methodology, contact the author at the email address provided on the title page.
