\section*{Data Availability and Replication Materials}
\addcontentsline{toc}{section}{Data Availability}

All research materials necessary to replicate the analyses in this dissertation are publicly available at the following repository:

\begin{center}
\textbf{\url{https://github.com/fabioc-aloha/AIRS_Data_Analysis}}
\end{center}

\vspace{0.5em}

The repository contains:

\begin{itemize}
    \item Anonymized Data: Complete survey responses (N = 523) in CSV and JSON formats
    \item Analysis Code: Python and R scripts for all statistical analyses (EFA, CFA, SEM, cluster analysis)
    \item Survey Instrument: The full 28-item AIRS questionnaire as administered
    \item Thesis Source: Markdown source files and build scripts for this document
    \item Figures and Tables: All visualizations and statistical output
\end{itemize}

\vspace{0.5em}

The data and code are released under dual licensing: MIT License for code and CC BY 4.0 for data and documentation. Researchers are encouraged to use these materials for replication, extension, or meta-analytic purposes with appropriate citation.

\vspace{0.5em}

For questions about the data or methodology, contact the author at the email address provided on the title page.
